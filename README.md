# AdminExpress - Login

Actividad en clase de Ingeniería Web (UDLA). Es una página de login hecha solo con HTML y CSS, que reproduce el diseño que nos dieron. Es responsive y se adapta a escritorio, tableta y móvil.

## Qué usé

- HTML
- CSS con Grid
- Media queries

## Cómo verlo

Descarga o clona el repositorio y abre `index.html` en el navegador.
